# Rock Paper Scissors

A web-based Rock Paper Scissors game built with Spring Boot and PostgreSQL. Players compete against a computer opponent, with all game rounds and scores persisted to a database.

## Features

- Play Rock, Paper, Scissors against a computer opponent
- Persistent game sessions with round-by-round history
- Live scoreboard (wins, losses, draws)
- Animated hand-clash battle interface
- REST API for playing rounds programmatically
- Fully containerized with Docker Compose

## Tech Stack

- **Java 17** with **Spring Boot 4.1**
- **Spring Data JPA** and **Hibernate** for persistence
- **PostgreSQL 16** as the database
- **Thymeleaf** for server-side rendering
- **Vanilla JavaScript** and CSS for animations
- **Docker** and **Docker Compose** for deployment
- **Maven** as the build tool

## Prerequisites

To run with Docker (recommended):
- Docker
- Docker Compose

To run locally without Docker:
- JDK 17+
- Maven 3.9+
- PostgreSQL 16

## Getting Started

### Option 1 — Run with Docker Compose (recommended)

```bash
git clone https://github.com/souravahmednirob/rps-game.git
cd rps-game
docker compose up
```

The app will be available at **http://localhost:8080**.

### Option 2 — Run locally

1. Start a PostgreSQL instance and create a database:

   ```sql
   CREATE DATABASE rock_paper_scissors;
   ```

2. Update `src/main/resources/application.yml` with your database credentials.

3. Build and run:

   ```bash
   ./mvnw spring-boot:run
   ```

## Configuration

The following properties can be overridden via environment variables:

| Variable | Default | Description |
|---|---|---|
| `SPRING_DATASOURCE_URL` | `jdbc:postgresql://localhost:5432/rock_paper_scissors` | JDBC connection URL |
| `SPRING_DATASOURCE_USERNAME` | `postgres` | Database username |
| `SPRING_DATASOURCE_PASSWORD` | `admin` | Database password |
| `SERVER_PORT` | `8080` | HTTP port the app listens on |
| `SPRING_JPA_HIBERNATE_DDL_AUTO` | `update` | Hibernate schema management |

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET`  | `/` | Home page |
| `POST` | `/games/start` | Start a new game (form param: `playerName`) |
| `GET`  | `/games/{id}` | View a game and play rounds |
| `POST` | `/games/{id}/play` | Submit a move (form param: `move`) |
| `GET`  | `/history` | List all games |
| `POST` | `/api/games/{id}/play?move={ROCK\|PAPER\|SCISSORS}` | REST endpoint returning JSON |

## Database Schema

The application uses two tables, auto-generated by Hibernate on first run:

- **`game`** — one row per game session (player name, scores, created timestamp)
- **`round`** — one row per round (moves, result, foreign key to game)
